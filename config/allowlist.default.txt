# herdr-continuum — programs that restore may relaunch.
#
# One program name per line. Matching is case-insensitive and ignores a path and
# a trailing .exe, so "nvim", "NVIM" and "/usr/bin/nvim" all match.
# Lines starting with # are comments; a line containing only * means "relaunch
# everything" (aggressive — one-shot commands get re-run too).
#
# Editors are handled specially: when an nvim/vim pane can be restored with
# `nvim -S <session file>` the plugin does that, whether or not nvim appears
# below. Agents (pi, claude, codex, …) are resumed by herdr itself and are not
# listed here.
#
# ssh/mosh are intentionally absent: reconnecting remote sessions unattended is
# usually not what you want after a reboot. Add them back if it is.
